# Project Agent Rules

This project uses the **GitHub Speckit** workflow for feature development and implementation.

## Guidelines

- **Default to Speckit for new features:** When working on new features, architecture changes, or significant implementations, you should use the available `speckit-*` skills (e.g., `speckit-plan`, `speckit-specify`, `speckit-implement`) to drive the development process.
- **Let the skills guide you:** Rely on the specific instructions and artifacts defined within the `speckit-*` skills to manage the workflow.
- **Ad-hoc edits are allowed:** For simple bug fixes, minor refactors, or when explicitly requested by the user, you may perform direct ad-hoc code edits without invoking the full Speckit process.
