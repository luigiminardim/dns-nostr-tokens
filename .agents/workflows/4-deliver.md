# Deliver Workflow

## Instructions

1. **Review:** Invoke the local `the-judge` skill to perform a rigorous, evidence-based review of the Pull Request or local diff. Address and fix any critical findings it highlights.

2. **Documentation Integrity:** Check if the newly developed code alters the architecture, setup commands, or domain model. If so, update `AGENTS.md`, `README.md`, or `docs/domain.md` accordingly. The code and docs must stay perfectly in sync.

3. **Ship:** Create a clean, comprehensive commit message and PR description summarizing the changes and referencing the issues that are closed by this work.

4. **Next Step Recommendation:** Inform the user that the Double Diamond workflow is complete and the feature is ready to be merged!
