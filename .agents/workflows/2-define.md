# Define Workflow

## Instructions
1. **Architectural Alignment:** Consult the local `clean-architecture` skill (`.agents/skills/clean-architecture/SKILL.md`) to determine exactly where the new changes will live within the Dependency Rule.

2. **Execution Plan Generation:** Use the local `tlc-plan` skill to parse the approved PRD and design the execution plan. Do **not** create local files (like `.tasks/<name>.md` or `plan.md`).

3. **Issue Generation:** Take the plan generated by `tlc-plan` and immediately create GitHub issues using the `gh issue create` CLI command.
   - **CRITICAL CONSTRAINT:** Do not create micro-tasks or overly small issues. Each issue must cover an **entire user story** or a **complete technical story**.

4. **Next Step Recommendation:** Once the issues are successfully created on GitHub, explicitly recommend that the user trigger the `3-develop` workflow to begin implementation.
